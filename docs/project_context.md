# Project context

This repository contains the project-specific curation, generation wrappers,
filtering, evaluation and target-preparation work for the MRes study of RNA
aptamers against carbapenemase targets. RNAGenesis model code is maintained in
the separate [RNAGenesis repository](https://github.com/laura-hardy/RNAGenesis).

The earlier LLM context document at this path described work in progress in
June 2026. It has been retired; this path is retained for existing references.
